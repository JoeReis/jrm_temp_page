Practical Data Media — offline site source

Unzip this archive and open index.html in your browser. No build or installation is required.

Edit index.html for content and links, styles.css for appearance, and script.js for interactions. Images are in assets/.

For a local development server, run this from the extracted directory:
  python3 -m http.server 8000
Then visit http://localhost:8000.

The contact and proposal forms prepare email drafts; they do not store or submit data to a server. External purchase and subscription links require internet access.

This export preserves the original mockup, including the old January 2027 Summit dates and provisional catalog details. Update these before public use.
